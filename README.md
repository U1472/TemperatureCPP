# TemperatureCPP

Программа для численного моделирования распределения температуры в стержне, нагреваемом с одного конца.

## Описание

Проект представляет собой академическую работу, целью которой является реализация и сравнение явной и неявной схем расчёта температуры. Программа позволяет задавать параметры материала, такие как теплоёмкость (c) и теплопроводность (λ), в виде констант или функций, зависящих от температуры.

**Модель и допущения:**
- Одномерный стержень длиной 1 м, нагрев с одного конца.
- Плотность материала постоянна и равна 1.
- Свойства материала (c, λ) одинаковы по всей длине стержня.
- Внешние факторы (теплоотдача в окружающую среду) не учитываются.

## Технологический стек

- **Язык:** C++
- **GUI:** WinAPI (Win32), шаблон «Классическое приложение Windows» в Visual Studio Community
- **Сборка:** Visual Studio Community (файл решения `.sln`)
- **Сторонние библиотеки:** пока не используются

## Начало работы

### Предварительные требования

- Visual Studio Community с установленной рабочей нагрузкой «Разработка классических приложений на C++».
- Windows SDK (ставится вместе с рабочей нагрузкой).

### Сборка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/U1472/TemperatureCPP.git

2. Откройте файл решения .sln из корня репозитория в Visual Studio Community.

3. Нажмите **Build** (Сборка → Собрать решение).

4. Запустите собранный .exe (**Ctrl+F5** или из папки сборки).

## Использование

1. Задайте параметры стержня и начальные условия.

2. Введите значения или функции для теплоёмкости (c) и теплопроводности (λ).

      Парсер математических выражений пока не реализован - см. TODO.md.

3. Переключите схему расчёта галочкой «Использовать явную схему?»:

- отмечена - явная схема;

- снята - неявная схема (реализация в процессе, см. TODO.md).

Запустите расчёт.

### Результаты

- Программа выдаёт результат в двух видах:

- **Число шагов**, за которое нагрелась последняя точка стержня.

- **График теплоты** (при ограниченном числе шагов): цветные секции, количество которых равно числу разбиений стержня. Цвет секции меняется от синего (холодная зона) до красного (нагретая зона).
