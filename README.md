Дальше у нас стоит несколько задач для реализации:

## Реализовать **неявную схему**
1. Переключение на неявную схему будет происходить по нажатию галочки
2. Строки while (fabs(pieces[intervalCount] - temperatureEnd) > accuracy && tMax >= t) {...} нужно заменить на проверку if-else по галочке. В случае true используется неявная схема. В случае false используется явная схема. 
## Сравнить что происходит при c и $\lambda$ **равными константе** и при c и $\lambda$ **не равными константе** 
1. В текстбокс c и $\lambda$ вписывается функция или значение. Значение воспринимается как константа. Функция отправляется в парсер (который на входе получает string с мат. формулами основанными на, например, LaTeX и на выходе даёт лямбда функцию, зависимую от T), после чего через лямбда функцию рассчитывается нужное значение во время хода программы.
## Сохранять результат итераций для будущей отрисовки на **график, где абсцисса=t, ордината=T конкретной точки** (x=1 (как сейчас), x=0.5)
1. Создаётся вектор массивов float.
2. Если итераций расчёта температуры до 100, то на каждой итерации сохраняется значение массива. Если итераций больше 100, то сохраняется итерация на каждом перцентиле (Если 1000 итераций, сохраняется каждая 10. Если 253, то каждая 2,53 с округлением до целых)
3. Отрисовка разделяет выделенное место на экране под все точки по порядку и равномерно, после чего закрашивает выделенные под эту точку пиксели в "цвет температуры" этой точки.
